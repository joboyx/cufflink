# Privacy policy

CuffLink collects no data. It stores no data and sends no data anywhere.

## What CuffLink reads

CuffLink reads the active tab only when you press the shortcut or click the toolbar icon. It reads:

- the page URL
- the tab title
- the page heading
- on a Jira board, the key and summary of the selected or focused card

It uses these values only to make the link label and the link target.

## What CuffLink writes

- The link, as rich text and plain text, to your clipboard.
- A result card in the page, which it removes after about 3 seconds.

## What CuffLink does not do

- It makes no network requests. The only file that it loads is its own bundled font, from inside the extension package.
- It does not use cookies, browser storage or extension storage.
- It has no analytics, tracking or remote code.
- It requests no host permissions, so it has no access to a site until you use it on that tab.

## Changes

A change to this policy ships in the repository with the release that needs it.
