# Security policy

## Supported versions

Only the latest minor release gets security fixes. Each fix ships as a new patch release of that minor version.

## Report a vulnerability

Do not open a public issue for a security problem.

Report it privately through [GitHub private vulnerability reporting](https://github.com/joboyx/jira-link-copy/security/advisories/new). Include the extension version, the Chrome version, the page type, the steps to reproduce and the effect. Use made-up URLs and titles, not ones from your company.

This is a volunteer project. The maintainer tries to reply within 14 days. When a fix is ready, the advisory is published with the release that contains the fix.
